# 🏙️ 3D 像素风城市建造游戏（City3D）

一个**单文件、双击即玩**的 3D 像素风城市建造小游戏。基于 Three.js 开发，无任何外部依赖，并内置了 **Minecraft 式的模组系统**——开源贡献者可以零门槛地添加新建筑、新兵种、监听游戏事件。

> ⚠️ 本项目由人类与 AI 协作开发：人类负责玩法设计、数值与规则决策，AI 辅助编码。许可证 MIT，欢迎自由使用与二次开发。

## ✨ 特性一览

- **双地图对战**：玩家城市 vs AI 对手（AI 会自己修路、盖房、开店、种田、建墙、造兵）
- **可解锁扩展土地**：主城南北各有一片土地，花钱解锁后即可扩建（存档兼容旧档自动迁移）
- **完整经济系统**：金钱、人口、电力（可与 AI 卖电）、食物（存粮/进口/售粮）、疾病与医院
- **科技与教育**：科技值 → 近现代/工业时代/现代三时代；初级学堂、大学（3×3 校园）、学费滑块、毕业体系
- **军队战争**：大头兵、坦克、狙击手（模组示例），可框选指挥、占领 AI 建筑、夺回政府大楼
- **像素风画面**：体素建筑（大学门廊圆顶、火电条纹烟囱、双格大道、粮仓麦堆……）、土地纹理、飘字特效
- **🎓 新手引导**：首次游玩自动弹出分步教程，完成对应操作自动进入下一步，顶部“📖 教程”可随时重看
- **存档系统**：localStorage 全量存档 + 每 60 秒自动存档 + 撤销（最多 5 步）
- **🧩 模组系统**：注册新建筑/新兵种/事件监听，几行代码即可扩展游戏（见 [docs/MODDING.md](docs/MODDING.md)）

## 🚀 快速开始

1. 下载本仓库
2. **双击 `city3d.html`**（保持 `lib/` 与 `js/` 文件夹在它旁边）即可游玩
3. 首次进入需先在地图上选择**政府大楼**的位置（3×3 空地）

> 也可用任意静态服务器托管：`python -m http.server` 后访问 `http://localhost:8000/city3d.html`

## 🎮 操作方式（电脑）

| 操作 | 功能 |
|---|---|
| 左键点击 / 拖动 | 放置建筑（拖动连续铺设） |
| 右键点击 | 拆除建筑（半价回收） |
| W / A / S / D | 移动视角 |
| Q / E | 环绕旋转 |
| R / F | 俯仰角 |
| 滚轮 | 缩放 |
| Ctrl+Z | 撤销 |
| 点击军营 | 全选军队并显示总兵力 |
| 选中军队后点击 | 移动 / 攻击敌军 / 占领对方建筑 |
| 🧨 拆除按钮 | 拆除模式（手机端替代右键） |

## 🧩 一分钟写一个模组

新建 `js/mods/my-mod.js`：

```js
GameMod.registerTile({
  key: 'TOWER', num: 200, name: '瞭望塔',
  cost: 200, button: { icon: '🗼', label: '瞭望塔', color: '#64748b' },
  builder: (group, r, c) => {
    GameMod.helpers.vox(group, 3, 10, 3, 0x64748b, 0, 5, 0);   // 一座高塔
  },
});
GameMod.events.on('placed', (p) => {
  if (p.type === TILE.TOWER) GameMod.helpers.status('🗼 瞭望塔建成！');
});
```

然后在 `city3d.html` 底部加一行 `<script src="js/mods/my-mod.js"></script>`，双击打开游戏即可在建筑菜单看到它。完整 API 见 [docs/MODDING.md](docs/MODDING.md)。

## 🎮 玩法速览

1. 落政府大楼（开局必选位置）→ 铺路 → 建住宅（人口增长）
2. 种小麦农场（粮食）、建太阳能（电力）、开店铺（收入）——悬停金钱可看收支明细
3. 建初级学堂/大学 → 科技值 → 进工业时代（军队变强）
4. 建军营 → 招募士兵/坦克 → 框选 → 进攻 AI 领土：打兵、拆墙（坦克）、占领建筑
5. 别让 AI 占领你的政府大楼，也别让城市断粮（饥荒会传染疾病、拖垮收入）
